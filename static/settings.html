Google Calendar

Two ways in. iCal is the quick one - paste the secret address from Google Calendar and you are done. OAuth gives you every calendar on the account, with colours, and survives a password change.

In Google Calendar: Settings → Integrate calendar → Secret address in iCal format. This is a credential - treat it like a password.

Must exactly match a redirect URI registered on the OAuth client.

Desktop app client — only http://localhost:<port> or http://127.0.0.1:<port>. Any port, any path. Use http://localhost:8099/oauth/callback.

Web application client — an exact HTTPS URI on a real hostname, e.g. https://board.longie.net/oauth/callback.

Google rejects a raw IP address (like http://192.168.1.6:8099) and plain HTTP on a hostname with Error 400: invalid_request. The board checks this for you.

Connect once, then choose here.

How many days the board shows, and how far ahead it reads the calendar. At 3 you get today, tomorrow and the day after. The board drops whole days when there is not enough room, so a small screen shows today first and the rest as space allows.

Google Photos

Paste a shared album link. The album must be shared with "Anyone with the link" - a private album will not load.

The transition is how long the board takes to change from one photo to the next - keep it shorter than the time each photo stays on the screen. Set the photo interval to 0 to stop the photos changing.
